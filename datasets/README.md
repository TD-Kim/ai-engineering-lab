# datasets

> 상태: **자리표시자**

실습에서 쓰는 데이터셋의 **설명·출처·라이선스·다운로드 방법**을 기록한다. 원본·가공 데이터는 커밋하지 않는다(`.gitignore`의 `datasets/raw/`, `datasets/processed/`).

## 원칙

- 라이선스가 명확한 공개 데이터셋만 사용하고, 출처 URL과 라이선스를 함께 적는다.
- 참고 저장소(강의 실습)의 데이터는 복사하지 않는다.
- Part 3·4·5의 비교 실험은 **같은 데이터셋·같은 분할**을 재사용한다.

## 디렉터리 (로컬 전용)

```text
datasets/
├── README.md        # 이 파일 (커밋)
├── raw/             # 내려받은 원본 (커밋 안 함)
└── processed/       # 청크·인덱스 입력 등 (커밋 안 함)
```
