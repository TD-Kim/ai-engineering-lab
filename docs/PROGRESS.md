# 진행 기록 (PROGRESS)

> 2026-11-16 학습 방식 전환: 정해진 실습 상태표(P1-01 … PF-01)는 폐지했습니다. 대신 **내가 직접 만든 것**을 날짜순으로 기록합니다. 이전 상태표는 커밋 `aa46d2f`의 이 문서에 있습니다(당시 모든 항목이 `NOT_STARTED`였고, 작성된 실습은 "학습자 확인 전"이었습니다).

## 상태값 규칙

| 상태 | 의미 |
|---|---|
| `NOT_STARTED` | 시작 전 |
| `IN_PROGRESS` | 진행 중 |
| `COMPLETED` | **학습자가 직접 확인한 것만** |

- `COMPLETED`는 **학습자가 직접 확인한 뒤**, 학습자가 바꾸거나 바꿔 달라고 요청할 때만 표시한다(Claude가 임의로 표시하지 않는다).
- 이전 실습 상태(P1-04·P1-01 등)의 갱신은 학습자 확인 후에 한다.
