- 직접 구현: `solution.BPETokenizer` (문자 단위 기본 기호 + `</w>`, 동점은 사전순, 특수 토큰 4개)

## 비교
- 같은 어휘 크기에서 토큰 수 차이는 3% 이내다. 병합 규칙이 52%만 겹치는 주된 이유는 기본 기호 집합이 다르다는 것이다. HF는 `도</w>`처럼 단어 끝 표시를 마지막 글자에 붙인 기호로 시작한다. 여기에 동점 처리 순서의 차이가 겹친다.
- 병합을 끝까지 하면 토큰 수가 단어 수(504)와 같아진다. 즉 단어 단위 토크나이저가 된다.
