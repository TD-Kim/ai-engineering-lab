# P1-05 Transformer (메인) — 실행 기록

- 실습 ID: P1-05 (메인)
- 날짜: 2026-11-12
- 실행 위치: 클라우드 작업 환경(CPU 4코어, 측정은 스레드 1). **GPU(RTX 3070) 수치는 사용자 PC에서 측정 필요**

## 목적
(1) 어텐션 손계산 값이 코드와 같은지, (2) √d_k 스케일이 softmax 포화를 막는지, (3) 시퀀스 길이 T에 따라 점수 행렬·시간이 어떻게 늘어나는지, (4) KV 캐시가 결과를 바꾸지 않고 계산을 줄이는지 확인한다.

## 데이터셋
- 손계산: x = [[1,0],[0,1],[1,1]] (토큰 3개)
- 나머지: `torch.Generator` 시드 고정 무작위 텐서(다운로드 없음)

## 모델
- 학습된 모델 없음. 어텐션 1회 계산(가중치는 단위행렬 또는 시드 고정 무작위)

## 비교
- 원소 수·메모리: T 2배 → 정확히 4배(결정적).
- 시간: 앞 T 대비 2.2~5.7배로 흔들림. 512 → 2048(T 4배)에서 약 10배.
- KV 캐시: 계산 행 32,896 → 256, 시간 약 1/5, 결과 차이 2e-06.
- `F.scaled_dot_product_attention`(bool 마스크 True=참여, `is_causal=True`)와 출력 일치(테스트). 한 행 전체를 가리면 직접 계산은 NaN, 이 torch 2.15 SDPA는 0(관찰).
