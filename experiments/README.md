폴더 이름: `<YYYYMMDD>-<짧은이름>/` (예: `20261117-ollama-chat/`)

- 목적: 무엇을 확인하려 했나
- 모델·설정: 모델 이름, 주요 설정값
- 결과: 실제로 측정한 값만(지연, 토큰 수, 비용, 품질). 측정하지 않은 값은 "측정 필요"
